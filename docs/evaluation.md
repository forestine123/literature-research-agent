# 验收与评测

## M0可自动验证的行为

离线演示正常输出；空检索在预算内停止；超时后尝试下一查询；DOI变体去重；伪造原文片段排除；论文ID错配排除；部分阅读失败可继续；空主题拒绝；数量上限与Markdown表格转义。

运行`uv run pytest`和`uv run ruff check .`。测试均不需要模型或学术API，不证明在线服务可用或语言模型内容正确。

## 真实评测设计（待实施）

准备3个计算机方向主题，每个5—10篇人工确认的论文，保存来源与使用权限，不将未经允许的全文上传仓库。固定阅读集与在线检索测试分别计分。

| 项目 | 记录方法 |
|---|---|
| 检索相关性 | 前10条人工相关判断，不足10条记录实际分母 |
| 字段提取 | 正确、错误、遗漏、原文未提供分别计数 |
| 证据存在 | paper_id、block_id、quote是否匹配 |
| 语义支持 | 人工标注支持、矛盾、无关、信息不足 |
| 跨文献比较 | 是否忽略数据集、指标和实验条件差异 |
| 运行开销 | 耗时、请求次数、可获取的token及缓存情况 |

基线为同模型、同材料的直接摘要汇总，实验组为结构化证据提取与比较。尽量保持输入预算一致，并公开差异。记录模型、提示、代码提交、参数、样本和错误案例，不预填提升率。

## 核验记录字段

任务ID、论文ID、内容层级、结论、证据片段、页段位置、存在性结果、语义支持标签、核验人（匿名编号）、备注。模型评分与人工结果分开保存。
