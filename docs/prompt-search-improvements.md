# 提示词与学术检索优化记录

## 本轮改动

- 将五阶段共享提示词集中到 `src/litresearch/workbench/prompts.py`，与具体任务指令共同发送。分别约束检索规划、相关性筛选与证据抽取、多文献比较、大纲和写作，保留原有结构化校验及预算机制。
- 候选排序由关键词子串匹配改为完整词项匹配；标题权重大于摘要，核心主题权重为 65%，最佳查询匹配为 35%。去重合并摘要后重新计算分数，避免长摘要或扩展词数量主导排名。这是启发式排序，不是语义相关性概率。
- arXiv 返回数量不足目标时，也允许一次缩短查询的补检索；仍遵守请求间隔，不进行无限扩展。
- 某来源返回 401、403 或 429 后停止该来源的剩余查询并记录跳过状态，其余来源继续。单次查询原有有限重试仍保留。

## 真实验证

任务 `44b3b139b9f94e0290864c970fc31451` 使用已保存的真实模型配置完成全流程。arXiv 和 OpenAlex 各三个查询成功，Semantic Scholar 首个查询限流后跳过剩余查询。

排序首位为 Face4RAG；CREAM-RAG 仅取得摘要；RGAR 医疗问答论文被模型判为不符合要求并排除。最终一篇全文、一篇摘要，四节报告，21 条原文可定位证据。32 次模型调用、112274 tokens，Markdown 导出 HTTP 200，确定性引用检查无错误。

42 项自动化测试通过。新增测试覆盖标题优先、避免子串误匹配、限流后停止后续查询、结果不足时有界扩展。Ruff 检查通过。

## 验收边界

该运行验证机制和来源可用性，不是固定样本的相关度提升实验；不能据此声称 Precision@K 提升。尚未引入通用网页搜索或新的搜索供应商，改进范围为现有学术联网检索。摘要分析不代表全文阅读，引用存在不代表语义全部正确。后续仍需多主题标注集、排序前后对照及数字口径人工审核。
