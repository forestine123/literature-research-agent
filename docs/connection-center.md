# 连接中心与界面更新

访问 `http://127.0.0.1:8765/#settings` 可以直接填写 API 配置。主工作台仍在 `http://127.0.0.1:8765/`。

## 使用顺序

1. 在“模型服务”填写 API Base URL、API Key、模型名称和协议。已有密钥显示星号，保留即可继续使用；修改服务地址时需要重新填写密钥。
2. 点击“保存配置”只保存到本机，不发起模型调用；点击“保存并测试连接”进行一次小规模真实模型请求。
3. 如需五个阶段使用同一服务，点击“将此服务用于全部五个 Agent”，然后保存。
4. 在“文献与向量”补充 OpenAlex、Semantic Scholar 密钥，可选语义 Embedding。arXiv 不需要密钥。
5. 填写完成后告知开发协作者，继续真实任务测试、引用核验与成本调优。

密钥不写入源码和报告，不存入浏览器 localStorage；本机数据库保存凭据，向网页返回掩码。调用时凭据发送给所配置的服务。此部署仅监听本机地址。
