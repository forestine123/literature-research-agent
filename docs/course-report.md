# 课程要求与选题报告编写

本页是原始课程材料的公开化整理，不含成员身份、学号、联系方式、教师个人信息或原始截图。

## 课题要求

设计并实现智能文献调研Agent，理解研究主题和调研要求，自动制定检索方案，调用学术工具获取相关论文，并开展阅读与信息提取。重点包括任务规划、工具调用和多文献协同分析。

## 选题报告

原模板无字数下限。本组按正文约2500—3000字组织，以下目标合计2600字，是内部规划，不是学校规定。

| 栏目 | 目标 | 内容 |
|---|---:|---|
| 成员情况 | 300字 | 每人真实基础与经历，正式提交稿在本地补充 |
| 任务与要求 | 500字 | 背景、目标、功能与边界 |
| 研究方案与关键技术 | 900字 | 架构、框架、自行实现机制、证据与验证方法 |
| 实施方案与计划 | 400字 | 里程碑、交付及主要风险 |
| 成员分工 | 250字 | 成员一至三的职责与接口协作 |
| 预期成果与形式 | 250字 | 系统能力、源码、测试记录、报告和演示 |

原模板栏目序号存在缺漏，正式填写时核对模板，不自行增加不存在的栏目。

研究方案可以基于docs/implementation-plan.md与architecture.md编写。首版计划使用真实模型和学术接口，但当前实现仅为M0离线基础；报告不能写成真实调研已经完成。

## 中期与最终报告

中期包含目标任务、完成情况、主要问题、下一步工作；至少保存一次真实流程演示、日志与未完成清单。

总结技术报告不少于8000字，包含中英文摘要、绪论及研究现状、需求或理论基础、设计实现、测试与结果分析、总结和参考文献。持续保存设计决策、测试与实验材料，避免最后补造过程。

课程截止日期与成员能力待小组确认。正式身份信息及学校原始Word模板留在本地，不进入本公开仓库。
