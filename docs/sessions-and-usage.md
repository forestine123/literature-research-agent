# 会话工作台使用说明

更新日期：2026-10-30。

在项目根目录运行 `./启动工作台.ps1`，打开 `http://127.0.0.1:8765`。已有模型配置会保留，无需重复填写密钥。

## 使用流程

1. 点击左侧「新建会话」，填写研究主题、关注点、年份和文献数量，确认数据源与预算后开始真实调研。「离线演示」使用合成材料，不调用真实模型。
2. 点击历史会话进入工作区；可以搜索会话、修改顶部名称。上方展示五阶段进度和本次调研用量。
3. 「调研报告」查看综述初稿并导出 Markdown/JSON；「文献库」查看来源、阅读层级及已缓存的原文 PDF；「证据索引」查看摘录和页码；「执行链路」展开工具调用与阶段产物，底部「完整运行记录」回放原始事件。
4. 在「研究对话」中追问方法、实验条件和证据缺口。消息自动保存，刷新后恢复。点击回答下方的证据按钮会切换到对应调研版本并定位证据。
5. 需要增加文献或重新生成报告时点击「追加调研」，修改条件后启动。同一会话保留多个调研版本，通过顶部下拉框查看旧报告与旧过程，不覆盖原来的成果。

桌面采用报告与对话双栏，小屏将对话移到报告上方；左侧历史入口可展开会话列表。会话名称和历史记录保存在本机 SQLite 中，不是云同步。

## 会话边界

追问基于当前选中版本的证据、论文阅读状态，以及最近最多 12 条完成消息（历史文本上限 12000 字符；证据序列化文本上限 50000 字符）。全部消息会保存，但不意味着每次都将完整历史传入模型。追问不会自动检索、重写报告或消耗原任务的剩余预算；使用独立调用预算，用量显示在回复下方。

引用 ID 校验可防止模型引用不存在的证据，但不能证明推理正确。真实测试中模型对“第二点”的指代出现偏差；建议明确论文标题或结论，并人工核验事实。候选文献包含筛掉的论文，阅读状态和筛选说明已加入会话上下文，避免将其误判为必须补读的材料。

原有任务首次启动自动迁移为独立会话。迁移前已备份数据库至本地忽略目录 `data/backups/`。历史 API 密钥不会出现在会话响应、报告或本文中。
