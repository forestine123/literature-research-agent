# PDF 排版与课程要求核对

核对日期：2026-11-01。

## 课程材料与交付边界

本次查看了上级目录的《选题图片.png》命题原图，并提取核对《报告模板/综合工程设计-3-总结报告2026.docx》的正文要求。命题涉及任务规划、文献检索工具、自动阅读提取和多篇文献综合分析；总结技术报告要求不少于 8000 字，包含中英文摘要、绪论、系统实现、调试与测试、参考文献等内容。

系统生成的文献调研成果是工程项目的输出样本，不能代替介绍系统设计、实现和测试的课程总结技术报告。本次没有将调研初稿标为已满足课程终稿要求，也没有补造实验结果。

## 下载与排版

报告工具栏的主按钮为「下载论文 PDF」，服务端直接返回 PDF 附件；HTML、Markdown 和 JSON 下载保留。历史已完成任务也可直接导出，无需再次调用模型。

PDF 采用 A4 页面、中文字体、分级标题、封面、可跳转目录、页眉和页码。较宽的比较表按逐篇文献的字段列表排版，保留所有单元格内容。证据索引与来源局限继续保留，便于核查。

自动插入的矢量图展示每篇文献已有证据数量，并附文献名称和阅读层级。图中数量来自任务数据，不表示论文质量或实验性能；本次未实现任意图片上传，也未复制来源论文中的图片。

Windows 默认嵌入系统宋体；其他部署环境建议通过 `LITRESEARCH_PDF_FONT` 指定可用中文字体文件。未找到字体时使用 ReportLab 的中文 CID 字体回退，跨阅读器显示效果需另行验证。依赖由 `uv sync` 安装。

## 界面调整

会话列表采用细滚动条、柔和颜色和稳定滚动区域，隐藏 WebKit 滚动条箭头；下载工具栏允许换行。宽屏保留报告与研究对话双栏，窄屏采用单栏。文字长标题允许换行，手机尺寸保留可点击的下载按钮。
