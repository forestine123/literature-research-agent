# 扩大资料覆盖与下载排版文档

新建调研默认选择 5 篇，保留 3 篇快速验证与 10 篇深入比较选项；默认预算调整为 600000 tokens、120 次模型调用，仍可在高级设置修改。篇数是候选上限，不代表全部相关或全部取得全文。

报告增加摘要、关键词、结论与展望。摘要与结论复用已绑定证据的综合分析，不额外编造资料；保留检索范围、来源状态、主题章节、文献比较表、证据索引、参考文献及局限说明。

任务完成后点击「下载论文 PDF」直接获取排版后的 PDF：

1. PDF 使用 A4 页面，包含封面、目录、页眉页码和文献证据覆盖图；长比较表转换为逐篇字段列表，保留内容并避免跨页裁切。
2. HTML 作为补充格式保留，可离线打开并跳转目录；系统当前不提供 Word 导出。
3. Markdown 适合继续编辑，JSON 保留任务结构化数据，下载入口均在报告工具栏。

HTML 不执行原文中的 HTML 或脚本，不加载外部图片；支持 A4 打印样式。自动生成结果仍属于文献调研初稿，不能替代课程技术报告或未经人工核验即作为发表论文。

验证：44 项测试通过，包含 HTML 目录、表格、原始 HTML 转义与未完成任务禁止导出；前端类型检查、构建及 Ruff 通过。浏览器已检查 HTML 预览的目录和表格显示、横向溢出情况。
